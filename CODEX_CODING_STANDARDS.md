# Codex Coding Standards

This file is kept for compatibility with older project `AGENTS.md` profiles. New and
updated projects should read the lighter files below instead.

- At session start: `CODEX_SESSION_RULES.md`
- Before final response after code edits, reviews, or risky generated output: `CODEX_REVIEW_CHECKLIST.md`

Do not add bulky incident notes here. Put short always-on rules in `CODEX_SESSION_RULES.md`
and detailed Codex failure-pattern checks in `CODEX_REVIEW_CHECKLIST.md`.
